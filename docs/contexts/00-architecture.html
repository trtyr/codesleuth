主循环 · Harness::run

  • RunOutcome 由 Cli 同时落 ~/.codesleuth/reports/<sid>.md + .json

向量与索引通道

  • EmbedClient 走 Qwen3 兼容 /embeddings, 1024d Matryoshka
  • build: plan_chunks (主块/超大滑窗/兜底) → compose_input → commit_build 单事务落 vectors.db
  • recall: EmbedClient::instruct_query → HNSW k×3 超采 → cosine 复算 → tombstone 过滤
  • format_recall_block 双向消费: VectorSearchTool 工具面 + first_user_suffix 一次性注入
  • HNSW 影子 (M=16 / EF_SEARCH=64 / MIN_HNSW_SIZE=100_000), 否则暴力

四道安全围栏

  • Fence: 词汇预检 + dunce canonicalize 复检, 越界返 CS3003
  • bootlock: flock 跨进程串行化 codegraph 引导与 vector 构建 (acquire_guard)
  • writeguard: snapshot + diff 自证任务起止无可归因变更
  • Audit JSONL: seq 单调追加 + G2 校验, recall 回灌唯一事实锚点
  • EvidenceStore.observe 登记 path → first seq, submit 阶段校验锚点
