向量索引子命令 — 组件调用关系架构图

codesleuth index --vector · CLI → orchestrator → build pipeline → store

入口与编排

  • Command::Index 接收 --vector 旗标
  • Cli::run 在 vector=true 时路由到 run_index_vector
  • run_index_vector 获取配置、bootlock、构造 EmbedClient
  • tokio Runtime block_on 驱动 build_vector_index

构建流水线

  • fingerprint 决定索引槽位
  • plan_chunks 三层规则（符号/滑窗/leftover）
  • existing_hashes + meta 判定 stale
  • compose_input 组装每块文本
  • EmbedClient 4 路并发批嵌入
  • commit_build 单事务 GC+upsert+meta

落点与契约

  • 产物：.codesleuth/indexes/<fp>/vectors.db
  • 入口来源：codegraph.db 符号表
  • 外部依赖：OpenAI 兼容嵌入端点
  • 并发安全：flock 引导锁（CS4016）
  • 错误码：CS4010/CS4015/CS4016/CS3001
  • 报告：eprintln! BuildReport
