vector_search · Component Architecture

read-only tool · src/tools/vector_search.rs · Tool trait → RecallEngine pipeline

Tool surface

  • VectorSearchTool implements Tool trait
  • query (required), k (default 8, clamp [1,10])
  • Missing query → USER_INPUT w/ hint
  • Empty hits → degraded message
  • Returns position pointers (read required)

Recall pipeline

  • 3-stage: HNSW k×3 → exact cosine → tombstone
  • ef_search = 64 oversample
  • Brute force fallback for small corpus
  • Returns Vec<(Chunk, f32)>
  • format_recall_block renders hits

Startup injection

  • setup_vector_layer builds RecallEngine
  • Same engine → register + inject prompt
  • Hits → format_recall_block → system prompt
  • Failure → audit log + degraded path
  • Hits may seed repomap (best-effort)
