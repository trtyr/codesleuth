Three-Layer Chunking

  • Layer 1: KEPT_KINDS symbol main block · docstring 上提 (chunk.rs:280-340)
  • Layer 2: sub_window_chunks 滑窗 100/15 行 (chunk.rs:177-244)
  • Layer 3: covered gaps leftover + 磁盘 walk 兜底 (chunk.rs:407-468)
  • 最终按 (file, line_start, symbol) 排序输出

Storage & Identity

  • chunk_key = file ⎉ symbol ⎉ line_start (store.rs:14-16)
  • chunks 表 + 唯一索引 idx_chunks_key (store.rs:69)
  • commit_build: GC + upsert + meta in unchecked_transaction (store.rs:170-232)
  • fingerprint 变 (model/dim/mode) 即全量重建 (build.rs:25-92)

Recall & Task Seed

  • RecallEngine: 暴力 ≤100k · HNSW >100k · tombstone >20% → compact (recall.rs:25-139)
  • format_recall_block 起步线索 + 相似度 + 免责 (recall.rs:142-159)
  • hit 喂 caller/callee 给 repomap::build_task_map (cli.rs:607-654)
  • build 失败非致命 · bootlock 串行 · degraded audit row
